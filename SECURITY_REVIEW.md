# Security review — WorkVault 1.5.0

Статусы: ✅ исправлено в этом патче · ⚠️ частично · ❌ осталось (нужно решение/инфра)

## Критичные
| # | Проблема | Статус |
|---|---|---|
| 1 | **Stored XSS в тексте сообщения**: `baseRender` не экранировал кавычки → `https://x"onmouseover=...` выходил из `href` | ✅ экранируются `"` и `'` |
| 2 | **XSS через linkMeta**: клиент мог прислать `url: javascript:...` / `image: data:...` | ✅ санитизация на сервере (`sanitizeLinkMeta`) и на клиенте (`safeUrl`) |
| 3 | **Stored XSS через загрузки**: фильтр `mime OR ext` + nginx отдавал `/uploads` без заголовков → HTML/SVG исполнялся на вашем origin | ✅ whitelist расширений + проверка сигнатур картинок, случайные имена, в nginx `nosniff` + CSP sandbox + `attachment` для не-медиа |
| 4 | **SSRF через /api/unfurl**: сервер с интернетом ходил на любой адрес, в т.ч. `cadvisor:8080`, `blackbox:9115/probe`, LAN `172.16.99.x`, `169.254.169.254` | ✅ резолв DNS с проверкой IP (private/loopback/link-local/CGNAT/IPv6 ULA), проверка на каждом редиректе (макс. 4), только порты 80/443, лимит 1 МБ / 8 с, однословные хосты запрещены |
| 5 | **Захват аккаунта через set-password**: любой мог задать пароль аккаунту без пароля | ✅ выключено по умолчанию (`ALLOW_LEGACY_PASSWORD_SETUP=false`), пароль сбрасывает админ: `POST /admin/api/reset-password/:id` |
| 6 | **Канбан без ACL**: любой пользователь читал/менял любые карточки по id | ✅ проверка доступа к зоне на каждом маршруте (зоны, колонки, карточки, подзадачи, теги), PATCH карточки — whitelist полей |
| 7 | **Electron auto-update по HTTP без подписи** → RCE через MITM | ❌ нужен HTTPS для фида обновлений + подпись сборок (code signing) |

## Высокие
| # | Проблема | Статус |
|---|---|---|
| 8 | CORS `origin: true` + credentials и нет CSRF-проверки | ✅ allowlist (`APP_URL`, vite dev, `CORS_ORIGINS`, Electron `null`) + проверка Origin на изменяющих запросах |
| 9 | Socket-события без валидации (чужой канал, чужие сообщения, огромные payload) | ✅ валидация типов/длин, канал берётся из БД, `maxHttpBufferSize 1 МБ`, простой rate-limit событий |
| 10 | Глобальный `io.emit` — события приватных задач видели все | ✅ чип приватной задачи уходит только в комнату `user:<id>` владельца, события канбана — по зоне |
| 11 | `/api/folders/update` доступен любому | ✅ только админ (кнопку в EditSidebar стоит скрыть для не-админов) |
| 12 | delete-user оставлял сессии и мусор; set-role не отзывал JWT (роль жила ещё до 15 мин) | ✅ транзакция, отзыв refresh-токенов, отключение сокетов |
| 13 | Electron `shell.openExternal` без фильтра схем (`file://`, `smb://`) | ✅ только http/https/mailto + запрет `will-navigate` на чужой origin |
| 14 | Открытая регистрация | ⚠️ флаг `ALLOW_REGISTRATION` (по умолчанию true — для закрытой команды ставь false) |

## Средние / низкие
| # | Проблема | Статус |
|---|---|---|
| 15 | Rate-limit только по `имя+IP` → перебор по разным именам | ✅ + лимит по IP (30/15 мин), nginx `auth_zone` на `/api/auth/` |
| 16 | Минимальный пароль 6 символов | ⚠️ для сброса админом 8; в регистрации стоит поднять до 8+ |
| 17 | Публичный `/api/users` отдавал role/has_password | ⚠️ без авторизации отдаются только id/имя/аватар/цвет/has_password (нужен экрану входа); флаг `PUBLIC_USER_LIST=false` закрывает список целиком |
| 18 | `e.message` в ответах 500 | ✅ общий текст, детали в лог |
| 19 | Неограниченный `limit` у `/api/messages` | ✅ clamp |
| 20 | Нет security-заголовков | ✅ в express и nginx (nosniff, X-Frame-Options, Referrer-Policy, HSTS) |
| 21 | `logAdmin` не писал, кто действовал | ✅ поле `by` |
| 22 | bootstrap-admin: слабый мастер-ключ | ⚠️ сравнение timing-safe, работает только пока нет ни одного админа; ключ всё равно держи длинным и убери из .env после |
| 23 | cadvisor `privileged`, `/downloads` и `/uploads` без авторизации | ❌ cadvisor не публиковать наружу (только во внутренней сети), `/uploads` по случайным именам, но без auth — для чувствительных файлов нужен `auth_request` |
| 24 | Admin stats с захардкоженным путём | ❌ косметика |

## Что уже было хорошо
PBKDF2 120k, хешированные и ротируемые refresh-токены, параметризованный SQL везде, DOMPurify, `contextIsolation` в Electron, httpOnly + SameSite=Lax куки.
