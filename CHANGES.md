# Изменения (патч поверх 1.5.0)

## Новое
- **Стикеры.** Кнопка в поле ввода → панель общего набора. Любой может добавить PNG/WebP/GIF до 1 МБ, удалить — автор или админ. Стикер отправляется по id (url берётся из БД, подменить нельзя), показывается 160×160 без рамки. Удаление из набора не ломает старые сообщения.
  - API: `GET/POST /api/stickers`, `DELETE /api/stickers/:id`; сокет `message:send` принимает `stickerId`; событие `stickers:update`.
  - Таблица `stickers` создаётся автоматически.
- **Личные пространства канбана.** При создании зоны галочка «Личное пространство» — видно только владельцу, на вкладке замок. Задачу из чата можно кинуть в личную зону: чип задачи увидит только владелец. Последнюю *общую* зону удалить нельзя, личные — можно.
  - Колонка `kanban_workspaces.owner_id` (NULL = общая) добавляется миграцией.

## Исправлено
- Бейдж «Готово» больше не наезжает на ярлык чата: он перенесён в футер карточки рядом с источником.
- Безопасность — см. `SECURITY_REVIEW.md`.

## Новые переменные .env
| Переменная | По умолчанию | Смысл |
|---|---|---|
| `CORS_ORIGINS` | пусто | доп. origin через запятую (кроме `APP_URL`) |
| `CORS_ALLOW_ELECTRON` | `true` | пускать Electron (`Origin: null`) |
| `ALLOW_REGISTRATION` | `true` | саморегистрация; для команды лучше `false` |
| `ALLOW_LEGACY_PASSWORD_SETUP` | `false` | старый «задай пароль сам» — включать только на время миграции |
| `PUBLIC_USER_LIST` | `true` | список имён на экране входа |

**Важно:** `APP_URL` теперь участвует в CORS/CSRF — на проде он должен точно совпадать с адресом в браузере (`https://172.16.99.37`), иначе запросы получат 403.

## Новый админский эндпоинт
`POST /admin/api/reset-password/:id` `{ "password": "..." }` — задать/сбросить пароль (≥ 8), сессии пользователя отзываются.

## Не проверено в песочнице
Фронт (`vite build`) не собирался — не было доступа к npm. Синтаксис серверных файлов, Electron и `<script>`-блоков изменённых .vue проверен `node --check`. Перед деплоем: `npm ci && npm run build`, прогнать вручную стикеры, личную зону, отправку ссылки с превью.
